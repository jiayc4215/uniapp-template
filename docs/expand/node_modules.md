# 清理 node_modules

`node_modules` 文件数量多、目录层级深，直接在文件管理器里删除通常很慢。本项目已经内置 `rimraf`，可以用脚本快速清理依赖目录和锁文件。

## 项目脚本

根目录 `package.json` 已配置：

```json
{
  "scripts": {
    "clean": "rimraf node_modules pnpm-lock.yaml"
  },
  "devDependencies": {
    "rimraf": "^6.1.3"
  }
}
```

执行：

```bash
pnpm clean
```

该命令会删除：

- `node_modules`
- `pnpm-lock.yaml`

如果只想重新安装依赖但保留锁文件，不要使用 `pnpm clean`，可以只删除 `node_modules`：

```bash
pnpm exec rimraf node_modules
```

## 重新安装

清理后重新安装：

```bash
pnpm install
```

安装完成后会自动执行 `postinstall` 中的 `weapp-tw patch`。

## 什么时候需要清理

- 依赖安装中断，导致本地依赖目录异常。
- 切换 Node 版本后出现原生依赖或构建缓存问题。
- 调整依赖版本后，本地表现和锁文件不一致。
- 需要重新生成 `pnpm-lock.yaml`。

一般情况下，优先保留 `pnpm-lock.yaml`，这样团队依赖版本更稳定。
