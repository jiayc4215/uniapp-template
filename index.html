项目结构

多端构建

使用 uni-app 3、Vue 3 和 Vite 5，内置 H5、微信小程序及其他小程序平台脚本。

路由与权限

通过 definePage、路由守卫、Pinia 登录态和角色规则实现页面访问控制。

UI 与样式

集成 Wot UI、Tailwind CSS 4、weapp-tailwindcss、暗黑模式和动态字体大小。

分包示例

使用 @uni-ku/bundle-optimizer，提供 echarts-modules 与 public-modules 分包示例。

Mock 与请求

开发环境可开启 better-mock，配合 src/api 和 src/utils 下的请求封装演示登录流程。

小程序上传

提供微信小程序构建与 CLI 上传脚本，便于接入发布流程。
